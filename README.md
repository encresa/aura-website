# AURA Website

The official landing page for Project AURA - The World's Fastest AI Secretary.

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 📦 Build for Production

```bash
npm run build
npm run preview
```

## 🌐 Deployment

This site is automatically deployed to GitHub Pages on push to `main`.

**Live URL:** https://encresa.github.io/aura-website

## 🎨 Design System

Built with the AURA Design Philosophy:
- **The Void & The Mirage** - Dark glassmorphic aesthetic
- **Ice Physics** - Smooth, decelerated animations
- **Living Entity** - Breathing, organic core visualization
